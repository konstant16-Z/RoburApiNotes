## Хост и модули (обе версии)

Все классы модулей **`internal`** и наследуют внутренний базовый класс-модуль
(`PluginInitializator`). В слоях de4dot baзы/модули получили квази-имена `ClassN` —
**нумерация локальна для сборки и версии**:

| Смысл (группа команд) | Новая 16.0.62 (`Slayed`) | Старая 16.0.50 (`Slayed_16_50`) |
|---|---|---|
| базовый модуль (`PluginInitializator`) | `Class35` | `Class33` |
| Размеры (19 `[cmd]`: `qdim`…`dimoverride`) | `Class36` | `Class34` |
| Рисование (59 `[cmd]`: `line`…`testcppoutput`) | `Class37` | `Class35` |
| Сравнение чертежей (2: `open_dwg_cmp`, `set_dwg_layer_color`) | `Class38` | `Class36` |
| Буфер обмена / порядок (11: `pasteblock`…) | `Class39` | `Class37` |
| Модификация (18: `offset`…`reverse_pline`) | `Class40` | `Class38` |
| Слои / свойства чертежа (46) | `Class41` | `Class39` |

Сопоставление версий подтверждено по содержимому (члены и типы параметров
совпадают 1:1; структура стабильна, нумерация сдвинута на +2).

## Что делает каждый модуль (по членам api-base + IL)

- **`Class36` (старая `Class34`)** — размеры: двумерные размерные примитивы
  (`DwgDimensionRotated`/`DwgDimensionAngular` в параметрах), 19 `[cmd]`.
- **`Class37` (старая `Class35`)** — рисование: ~80 методов `() → void`
  (обработчики команд + помощники), полилинии с офсетом (`DwgOffsetedPolyline`),
  мультилинии (`MLineJustification`), вставка блоков/образов.
- **`Class38` (старая `Class36`)** — сравнение чертежей: всего 4 члена —
  `BeforeExecute`/`ValidateWindow` (окно ValidateWindow) и 2 метода (одна cmd —
  `method_5(object[])`, вторая работает с `Dwg.Drawing`).
- **`Class39` (старая `Class37`)** — буфер обмена / порядок: 11 `[cmd]`.
- **`Class40` (старая `Class38`)** — модификация: сегменты и сопряжения линий
  (`DwgLine`/`DwgArc`/`DwgPolyline`, интерфейс `ILinearJoinable`), вставка.
- **`Class41` (старая `Class39`)** — слои/свойства чертежа: 46 `[cmd]`.

## Внешний контракт

- Классы модулей **`internal`** — наружу не смотрят и в API не входят; имена
  обфусцированы во всех версиях (в `Bin` — юникод-мусор, в `Slayed` — квази-имена
  de4dot). **Исходные имена не восстановимы** ни из метаданных, ни из базы.
- Реальный публичный контракт — **строки `[cmd]`** (значения атрибутов не
  обфусцированы) и манифест `*.plugin`. Вызывать команды из своих плагинов —
  только через `ApplicationHost.Current.Plugins.Execute("имя_команды", …)`,
  не ссылаться на типы контроллера.
- Словарь имён команд — из IL (`Tools/IL/DwgController_Slayed.il`, атрибуты `cmd`)
  и секций `actions`/`menubars` манифеста. **В `api-base` кастомных атрибутов нет.**

## ⚠️ Ловушки (Pitfalls)

- **`ClassN` — нет, просто «Class36» в базе**: de4dot нумерует глобально по корпусу,
  `Class36` встречается в сотнях сборок. Всегда уточнять сборку + слой + версию.
  Запрос `LIKE '%Dwg.Controller'` ловит и родственную сборку
  **`Topomatic.EmtDwg.Controller`** (`EmtDwgPluginHost`, ~другая нумерация модулей) —
  не путать.
- **Сдвиг нумерации между версиями +2**: `Class36` в `Slayed_16_50` — это
  «сравнение чертежей», а в `Slayed` — «размеры». При переносе заметок между
  версиями сверять по содержимому, не по имени.
- **Счёт `[cmd]` по сигнатурам не работает**: cmd-методы бывают `()`, `(string)`,
  `(object[])` вперемешку с помощниками (пример `Class38` — одна команда
  `method_5(object[])`, вторая — метод с `Dwg.Drawing`), атрибуты в БД не
  сканируются. Точный инвентарь — только слой Slayed/IL.
- **`Bin`-слой бесполезен для имён**: имена модулей там — юникод-мусор, из слоя
  можно извлечь лишь структуру (чего и достаточно — она совпадает со `Slayed`).
