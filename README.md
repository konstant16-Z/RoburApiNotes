# ApiNotes — проверенный справочник по API Robur

Единый источник подтверждённых данных по API «Топоматик Робур». Собирает и структурирует
информацию по проектам [PluginExample-main](https://github.com/konstant16-Z/PluginExample-main)
и внешним боевым плагинам, дополняя
[AGENTS.md](https://github.com/konstant16-Z/PluginExample-main/blob/main/AGENTS.md)
(там остаётся только краткий конспект + ссылка на справочник).

Справочник развивается в отдельном репозитории
[RoburApiNotes](https://github.com/konstant16-Z/RoburApiNotes) и подключается к исходному
проекту как Git-субмодуль `ApiNotes/`. Упоминания `AGENTS.md`, `Development/`, `Tools/`,
`RailModelImporter/` и других проектов ниже и в тематических файлах относятся к исходному
проекту или указанным внешним источникам: эти файлы не входят в данный репозиторий.
Сборки Robur здесь не распространяются.

**Правило №1 — никаких выдуманных имён.** Каждая запись обязана иметь источник (см. статусы ниже).
Если имя класса/метода не подтверждено ни декомпиляцией, ни кодом, ни туториалом — его здесь нет.

## Статусы подтверждения

| Статус | Метка | Что означает |
|---|---|---|
| Декомпиляция | `[DECOMP]` | Прямая декомпиляция `*.dll` (ilspycmd) — публичный API цел, даже если Stg-поля обфусцированы |
| Боевой код | `[CODE]` | Проверено рабочим плагином (Runoff/DemLoader/RoadStyle/ModelDesk) — живой прогон, не туториал |
| Туториал | `[TUT]` | Паттерн из официальных примеров TopomaticRobur/PluginExample |
| Рефлексия | `[REFL]` | Рефлексия по SDK (без декомпиляции), указана версия Robur |
| Гипотеза | `[HYP]` | Не подтверждено — в справочник не попадает, только в обсуждение |

`[DECOMP]` и `[CODE]` — наивысшая достоверность. `[TUT]` — надёжно, но у официальных
примеров есть известные баги (см. AGENTS.md).

## База источников

| Источник | Что из него берём |
|---|---|
| `Development/Out/Bin/Topomatic.*.dll` | Декомпиляции (эталонный SDK в репозитории) |
| `Runoff`, `DemLoader`, `RoadStyle`, `ModelDesk` (копии `/tmp/opencode/external/`) | Боевые паттерны, минимальная версия Robur **16.0.62.12**; рефлексия SDK 16.0.60.11 (ModelDesk) |
| `New_export/src/DxfExport` + `New_export/SPECIFICATION.md` | DWG-сущности, листы, CadColor, запись DXF/DWG через ACadSharp, скриптовый слой (IronPython/PyBridge) |
| `RailModelExporter` (`PyBridge.cs`, `SCRIPTS-DISCOVERY.md`) | Паттерн C#→IronPython моста, факты по скриптовому движку |
| `https://help.topomatic.ru/next` (веб-справка: tutorial/reference) | `[TUT]`-паттерны cmd/plugin/cadcursors; пространства имён — **только перечни типов, без членов**; есть опечатки (`GetDouble "в радианах"`, `DrainSideConveter`, «Сторонна») — сигнатуры брать из `asmread`/декомпиляции |
| Туториалы корня репозитория (tutorial1–11, PascalCase) | `[TUT]` — каркас плагина, чертёж, ведомости |
| AGENTS.md | Конспект; полные таблицы разнесены по файлам этой папки |

**Версии:** боевые плагины Y-Abramov ≥ 16.0.62.12; SDK в `Development/Out/Bin` — эталон
для декомпиляций. API на разных версиях может отличаться — перед использованием сверяйте
`asmread`-ом (см. `Tools/`).

## Как пополнять

Правки вносятся в этот репозиторий (`RoburApiNotes`); в исходном проекте после значимых
обновлений подтягивается новая версия субмодуля.

1. Новый факт → файл по теме, строка в таблице.
2. Обязательно пометить статус `[DECOMP]`/`[CODE]`/`[TUT]` и источник (DLL или путь к файлу, строка).
3. Сначала проверка: декомпиляция (`ilspycmd`/`asmread`) или живой код — гипотезы не записывать.
4. Если факт противоречит AGENTS.md — правка AGENTS.md (источник истины), не дублирование.

Полные доказательства по конкретным темам — в `RailModelImporter/SPEC-*.md` и `Tools/README.md`.
